# Code-Quality-Agent

## Purpose
Monitors the codebase to ensure all Python, JavaScript, and configuration files remain clean, concise, readable, and written in a natural, human-engineered style.

## Responsibilities
- Prevents unnecessary commentary, repetitive inline notes, and obvious explanations.
- Eliminates leftover debugging statements, unused variables, and abandoned drafts.
- Enforces consistent naming, clear control flow, and idiomatic framework patterns.
- Guarantees alignment with existing frontend interfaces without unsolicited rework.
